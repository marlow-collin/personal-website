About

Selected Projects

Specialising an Open Source LLM for Marine Engineering Applications within Hardware Constraints using LoRA Fine Tuning

In this thesis, I fine-tuned a resource-efficient small language model based on Microsoft’s Phi-3 architecture for marine engineering and oceanography-related tasks using supervised fine-tuning and LoRA.

A second focus of the project was adapting the model to use the xVal number-encoding approach in order to improve the handling of numerical data.

Python · PyTorch · HuggingFace Transformers · CUDA · NumPy · pandas

Simulation and Prediction of Saliency Maps for People with Impaired Visual Perception using Convolutional Neural Networks

This thesis explored the prediction of visual saliency for people with different types of simulated visual impairments, including reduced contrast, color blindness and macular degeneration.

The project focused on adapting an existing saliency prediction model to learn impairment-specific saliency patterns while still using the original image as input.

Unified or Divided Through Sentiment? A Party Analysis of Parliamentary Speeches

This project analysed speeches from the German Bundestag to examine differences in party unity based on sentiment and language patterns.

The focus was on building a custom text parsing pipeline, preparing and analysing parliamentary speech data and evaluating sentiment differences between governing, opposition and fringe parties.
